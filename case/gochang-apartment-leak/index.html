현장에서 확인한 과정

사진과 현장 기록에서 확인되는 내용만 정리했습니다. 물이 보이는 위치만으로 원인을 단정하지 않고 탐지 결과를 비교한 뒤 필요한 범위만 개방했습니다.

냉수·온수 계통 구분

계량기와 배관 상태를 이용한 약식검사로 어느 계통을 우선 살펴볼지 범위를 정했습니다.

가스탐지

온수배관에 탐지용 혼합가스를 이용해 베란다 출입구 주변으로 범위를 좁혔습니다.

전자식 청음탐지

가스 반응만으로 개방하지 않고 주변 여러 지점의 누수음을 비교했습니다.

개방 위치 최종 확인

가스와 청음 반응이 겹치는 베란다 출입구 주변을 개방 위치로 정했습니다.

타일 아래 물기 확인

필요한 범위의 타일을 걷어내자 실제 물기와 미세한 기포가 확인됐습니다.

온수배관 누수 확인

배관을 노출해 온수배관에서 실제 물이 새는 지점을 확인했습니다.

문제 구간 부분교체

직접 확인한 범위에서 상태가 좋지 않은 온수배관 구간을 필요한 만큼 교체했습니다.

보수 후 2차 압력검사

타일 마감 전에 다시 압력을 걸어 추가 압력 손실이 없는지 확인했습니다.

타일 복구

검증 후 기존 타일과 이질감이 적도록 개방 부위를 복구했습니다.

이 사례에서 확인된 핵심

천장에 물이 보이는 위치와 실제 매립 수도배관의 누수 지점은 다를 수 있습니다. 이 현장에서는 압력 상태와 탐지 반응을 비교해 범위를 좁힌 뒤 실제 배관을 노출해 원인을 확인했습니다. 배관 보수 후에는 2차 압력검사로 압력이 유지되는지 확인한 다음 마감했습니다.
